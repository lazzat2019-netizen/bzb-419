Информатика пәні мұғалімі Мадетхан Л. үшін тәуелсіз БЖБ платформасы.

## Күйі

Бұл — сыртқы Cloudflare хостингіне орналастыруға дайын бастапқы код. Әзірге жарияланған сыртқы сайт емес. Хостинг пен Google кіру параметрлері бапталғаннан кейін жұмыс істейді. Google OAuth тексерістері жергілікті сынақтармен тексерілді; нақты Google аккаунтымен соңғы тексеру жариялағаннан кейін жасалады.

Мұғалім: **lazzat2019@gmail.com**. BilimClass логині бұл нұсқада қолданылмайды.
Оқушы: мұғалім берген жеке тапсырма сілтемесімен кіреді, Google аккаунтын талап етпейді.

## Не сақталған?

- Бұрынғы браузерлік тексеру бөлімі.
- Жиынтық бағалау бөлімі, сынып, оқу мақсаттары, оқушыға нұсқаулық.
- Бір жұмыста 1–10 нұсқа, әр нұсқада 1–30 тапсырма.
- Тапсырма суреті: PNG, JPG, WebP, 5 МБ-қа дейін; файлмен немесе Ctrl+V арқылы.
- Нақты жауаптарды автоматты тексеру, ашық жауаптарды мұғалімнің бағалауы.
- Жауаптарды жинау, 10 секунд сайын жаңа жауаптарды тексеру, қабылдауды жабу/ашу, CSV есеп.
- Тапсырма мен жауаптар D1 дерекқорында, суреттер R2-де сақталады.

Ескі сайттағы жарияланған жұмыстар мен жауаптар бұл архивке кірмейді және автоматты көшірілмейді. Ескі браузерлік деректерді бұрынғы сайттан экспорттау қажет.

## 1. GitHub-қа жүктеу

1. Архивті компьютеріңізде ашып, ішіндегі файлдарды шығарыңыз.
2. `lazzat2019-netizen/bzb-419` репозиторийінде **uploading an existing file** басыңыз.
3. Архивтің ішіндегі `worker`, `scripts`, `migrations` қалталарын және түбірдегі `package.json`, `wrangler.jsonc`, `README.md` файлдарын жүктеңіз. Қалталар құрылымы сақталсын. ZIP-тің өзін жүктемеңіз.
4. **Commit changes** басыңыз.

Репозиторийде бағдарлама коды ғана болады. Құпияларды, нақты жауап кілттерін, оқушылардың жұмыстарын GitHub-қа жүктемеңіз. GitHub Pages бұл серверлік платформаны толық іске қоспайды.

## 2. Cloudflare аккаунты және бастапқы орта

Cloudflare аккаунтыңызға кіріңіз. Workers, D1 және R2 мүмкіндіктері қажет. Тариф, тегін квота, төлем әдісін қосу талабы аккаунт пен қолданысқа байланысты: қызметті қоспас бұрын Cloudflare көрсеткен шарттарды қарап шығыңыз. GitHub қосылуы Cloudflare аккаунтының орнына жүрмейді.

Жобаны жергілікті компьютерде немесе GitHub Codespaces ортасында ашыңыз. Node.js 24 немесе жаңарақ нұсқа қажет (сынақтар Node.js SQLite модулін қолданады).

```bash
npm install --save-dev wrangler
npx wrangler login
npx wrangler d1 create bzb419
```

Шыққан нақты `database_id` мәнін `wrangler.jsonc` ішіндегі `REPLACE_WITH_YOUR_D1_DATABASE_ID` орнына жазыңыз. Бұл идентификатор құпия кілт емес. Нақты мәнді ойдан жазбаңыз.

```bash
npx wrangler r2 bucket create bzb419-images
npm run db:migrate
npm test
npm run deploy
```

`npm run deploy` шыққаннан кейін нақты `https://…workers.dev` мекенжайын сақтаңыз. Сайт осы кезде ашылады, бірақ Google параметрлері енгізілмейінше мұғалім кіре алмайды. Оқушы жауаптары тапсырма жарияланғаннан кейін ғана жиналады.

## 3. Google арқылы кіруді баптау

Google Cloud / Google Auth Platform ішінде өз жобаңызды таңдаңыз немесе жаңасын құрыңыз.

1. Branding бөлімінде қолданба атауын, өз байланыс email-ыңызды енгізіңіз.
2. Audience: External. Тестілеу режимінде `lazzat2019@gmail.com` аккаунтын Test users тізіміне қосыңыз.
3. Clients → Create client → Web application.
4. Authorized redirect URIs өрісіне **нақты сайт мекенжайыңызды** және `/auth/callback` жолын қосыңыз. Мысалы, өз доменіңіз `https://СІЗДІҢ-САЙТ.workers.dev` болса, redirect URI — `https://СІЗДІҢ-САЙТ.workers.dev/auth/callback`. Бұл мысалды сол күйінде көшірмеңіз.
5. Google берген Client ID мен Client Secret-ті Cloudflare құпия параметрлеріне енгізіңіз. Олар кодта немесе чатта сақталмайды.

Терминалмен енгізу:

```bash
npx wrangler secret put GOOGLE_CLIENT_ID
npx wrangler secret put GOOGLE_CLIENT_SECRET
npx wrangler secret put SESSION_SECRET
```

Әр пәрмен өз мәнін жасырын сұрайды. `SESSION_SECRET` үшін пароль менеджерінде кемінде 32 таңбадан тұратын кездейсоқ құпия жасаңыз. Бұл архивте дайын құпия жоқ.

Google кіруі ЖИ API-ін қолданбайды. ЖИ арқылы ашық жауаптарды бағалау бұл нұсқаға қосылмаған; оларды мұғалім бағалайды.

## 4. Алғашқы тексеру

1. Нақты сайттағы `/online` бетін ашыңыз.
2. «Google арқылы мұғалім ретінде кіру» батырмасын басыңыз, `lazzat2019@gmail.com` таңдаңыз.
3. Бір қысқа сынақ тапсырмасын жариялаңыз.
4. Оқушы сілтемесін инкогнито терезеде ашып, сынақ жауабын жіберіңіз.
5. Мұғалім бетінде жауаптың келгенін тексеріңіз.
6. Сурет жүктеп, оқушы бетінде көрінетінін және ашық тапсырмаға балл қою сақталатынын тексеріңіз.

Google `redirect_uri_mismatch` көрсетсе, Cloudflare берген нақты домен мен Google Clients ішіндегі redirect URI таңба-таңбасымен бірдей болсын.

## Қорғаныс

Google ID token қолтаңбасы, issuer, audience, expiry және nonce серверде тексеріледі. OAuth state және PKCE қолданылады. Сессия HMAC арқылы қол қойылып, HttpOnly/Secure cookie-де 8 сағат сақталады. Сырттан келген identity headers өшіріледі. Мұғалім API-лері тек рұқсат берілген Google аккаунтының тексерілген сессиясымен ашылады. Оқушы API-лері дұрыс жауап кілтін қайтармайды. Суреттер тек сол тапсырманың сілтемесі арқылы көрсетіледі.
