# Информатика · №419 кабинет — D1 нұсқасы

Информатика пәні мұғалімі Мадетхан Л. Мұғалімнің Google аккаунты: lazzat2019@gmail.com.

Бұл жинақта R2 қажет емес. Суреттер D1-де BLOB түрінде сақталады. Сурет бастапқыда 5 МБ-тан аспауы керек; браузер үлкен суреттерді жүктеу алдында 500 КБ-қа дейін ықшамдайды. Суреттегі мәтіннің анықтығын алдын ала қарап алыңыз. Сервер де 500 КБ шегін тексереді.

## GitHub-қа жүктеу

1. ZIP архивін шығарыңыз.
2. bzb-419 репозиторийінде Add file → Upload files → Choose your files ашыңыз.
3. Жаңа архивтен шығарылған файлдардың бәрін таңдаңыз, Commit changes басыңыз.
4. Бұрынғы worker/scripts/migrations қалталарын жою қажет емес: жаңа баптау түбірдегі файлдарды қолданады.
5. Cloudflare соңғы commit-ті жариялайды. Егер өзі басталмаса, ең соңғы Build-ті Retry арқылы қайталаңыз.

wrangler.jsonc файлына скриншотта берілген нақты database_id енгізілді. R2 байланысы жоқ. Құпия кілттер бұл жинаққа кірмейді.

## Дерекқор кестелерін дайындау

Cloudflare → Storage & databases → D1 → bzb419 → Console бөлімін ашыңыз. D1_SETUP.sql мәтінін SQL өрісіне көшіріп, орындаңыз. Ол тек жетіспейтін кестелер мен индекстерді құрады, бар жұмыстар мен жауаптарды өшірмейді.

Терминалмен жұмыс істесеңіз, балама пәрмен:

npx wrangler d1 execute bzb419 --remote --file=D1_SETUP.sql

Жаңа ортада стандартты миграция жолын пайдалансаңыз, npm run db:migrate қолданылады. Егер Console арқылы дайындап қойған болсаңыз, кейін миграцияларды өз бетінше қайта қолданбаңыз: миграция журналы бөлек жүргізіледі. Кестелерде нақты дерек бар кезде оларды жоюға болмайды.

## Google арқылы мұғалім кіруі

Хостинг жарияланғаннан кейін Google кіруін бөлек баптау қажет. Ол аяқталмайынша мұғалім кіре алмайды.

Google Auth Platform ішінде Web application клиентін жасаңыз. Тестілеу режимінде Test users тізіміне lazzat2019@gmail.com қосыңыз. Authorized redirect URI: өзіңіздің нақты HTTPS сайт мекенжайыңыз + /auth/callback.

Cloudflare Worker → Settings → Variables and Secrets ішінде үш құпия енгізіледі:

- GOOGLE_CLIENT_ID — Google берген клиент ID.
- GOOGLE_CLIENT_SECRET — Google берген клиент құпиясы.
- SESSION_SECRET — кемінде 32 таңбалық кездейсоқ құпия.

Олардың мәндерін GitHub-қа немесе чатқа жібермеңіз. Құпиялар осы архивте жоқ. Сайт доменін ауыстырсаңыз, Google redirect URI-ін де жаңартыңыз.

## Тексеру

Жергілікті сынақтар: Node.js 24 ортада npm test.
Тапсырма құру, екі нұсқа, кілтті жасыру, оқушы жауабы, қайталап жіберуді өңдеу, қолмен бағалау, қабылдауды жабу, D1 суреттері, шектен үлкен суретті қайтару, сессия мен Google токенін тексеру қамтылған.
Нақты Cloudflare сайтында және Google аккаунтымен соңғы тексеру орналастыру мен құпияларды баптағаннан кейін жасалады. ЖИ API бұл нұсқаға қосылмаған.

Жұмыс тәртібі: /online → Google арқылы мұғалім ретінде кіру → тапсырма жариялау → оқушы сілтемесін тарату → жауаптарды мұғалім бетінде көру. Оқушыға Google аккаунты керек емес.

Ескі ChatGPT сайтындағы жұмыстар мен жауаптар бұл код архивіне кірмейді және автоматты көшірілмейді. Бұрынғы браузерлік тексеру бөлімі сақталған, бірақ басқа домендегі localStorage деректері өздігінен көшпейді.

D1/Workers тегін жоспарларының лимиттері бар. R2 қосу немесе ақылы жоспарға ауысу бұл нұсқаны орналастыру үшін талап етілмейді; аккаунтыңыздағы белсенді тарифті өзгерту қажет емес.
