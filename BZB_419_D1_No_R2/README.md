# Информатика · №419 кабинет — D1 нұсқасы

Информатика мұғалімінің жұмыс кеңістігі. Рұқсат берілген Google аккаунттары auth.js ішіндегі ALLOWED баптауында сақталады.

Бұл жинақта R2 қажет емес. Суреттер D1-де BLOB түрінде сақталады. Сурет бастапқыда 5 МБ-тан аспауы керек; браузер үлкен суреттерді жүктеу алдында 500 КБ-қа дейін ықшамдайды. Суреттегі мәтіннің анықтығын алдын ала қарап алыңыз. Сервер де 500 КБ шегін тексереді.

## GitHub-қа жүктеу

1. ZIP архивін шығарыңыз.
2. bzb-419 репозиторийінде Add file → Upload files → Choose your files ашыңыз.
3. Жаңа архивтен шығарылған файлдардың бәрін таңдаңыз, Commit changes басыңыз.
4. Бұрынғы worker/scripts/migrations қалталарын жою қажет емес: жаңа баптау түбірдегі файлдарды қолданады.
5. Cloudflare соңғы commit-ті жариялайды. Егер өзі басталмаса, ең соңғы Build-ті Retry арқылы қайталаңыз.

wrangler.jsonc файлына скриншотта берілген нақты database_id енгізілді. R2 байланысы жоқ. Құпия кілттер бұл жинаққа кірмейді.

## Дерекқор кестелерін дайындау

Cloudflare → Storage & databases → D1 → bzb419 → Console бөлімін ашыңыз. D1_SETUP.sql мәтінін SQL өрісіне көшіріп, орындаңыз. Ол тек жетіспейтін кестелер мен индекстерді құрады, бар жұмыстар мен жауаптарды өшірмейді.

Терминалмен жұмыс істесеңіз, балама пәрмен:

npx wrangler d1 execute bzb419 --remote --file=D1_SETUP.sql

Жаңа ортада стандартты миграция жолын пайдалансаңыз, npm run db:migrate қолданылады. Егер Console арқылы дайындап қойған болсаңыз, кейін миграцияларды өз бетінше қайта қолданбаңыз: миграция журналы бөлек жүргізіледі. Кестелерде нақты дерек бар кезде оларды жоюға болмайды.

## Google арқылы мұғалім кіруі

Хостинг жарияланғаннан кейін Google кіруін бөлек баптау қажет. Ол аяқталмайынша мұғалім кіре алмайды.

Google Auth Platform ішінде Web application клиентін жасаңыз. Тестілеу режимінде Test users тізіміне auth.js файлындағы рұқсат етілген email қосыңыз. Authorized redirect URI: өзіңіздің нақты HTTPS сайт мекенжайыңыз + /auth/callback.

Cloudflare Worker → Settings → Variables and Secrets ішінде үш құпия енгізіледі:

- GOOGLE_CLIENT_ID — Google берген клиент ID.
- GOOGLE_CLIENT_SECRET — Google берген клиент құпиясы.
- SESSION_SECRET — кемінде 32 таңбалық кездейсоқ құпия.

Олардың мәндерін GitHub-қа немесе чатқа жібермеңіз. Құпиялар осы архивте жоқ. Сайт доменін ауыстырсаңыз, Google redirect URI-ін де жаңартыңыз.

## Тексеру

Жергілікті сынақтар: Node.js 24 ортада npm test.
Тапсырма құру, екі нұсқа, кілтті жасыру, оқушы жауабы, қайталап жіберуді өңдеу, қолмен бағалау, қабылдауды жабу, D1 суреттері, шектен үлкен суретті қайтару, сессия мен Google токенін тексеру қамтылған.
Нақты Cloudflare сайтында және Google аккаунтымен соңғы тексеру орналастыру мен құпияларды баптағаннан кейін жасалады. ЖИ API бұл нұсқаға қосылмаған.

Жұмыс тәртібі: /online → Google арқылы мұғалім ретінде кіру → тапсырма жариялау → оқушы сілтемесін тарату → жауаптарды мұғалім бетінде көру. Оқушыға Google аккаунты керек емес.

Ескі ChatGPT сайтындағы жұмыстар мен жауаптар бұл код архивіне кірмейді және автоматты көшірілмейді. Бұрынғы браузерлік тексеру бөлімі сақталған, бірақ басқа домендегі localStorage деректері өздігінен көшпейді.

D1/Workers тегін жоспарларының лимиттері бар. R2 қосу немесе ақылы жоспарға ауысу бұл нұсқаны орналастыру үшін талап етілмейді; аккаунтыңыздағы белсенді тарифті өзгерту қажет емес.

## 2026-11-25 жаңартуы — Бағалау студиясы

Cloudflare-дегі **Root directory** бұрынғыдай `BZB_419_D1_No_R2` болып қалады. Жаңарту бар тапсырмаларды, жауаптарды, Google кіруін және D1 суреттерін сақтайды. R2 немесе ақылы AI қосылымын міндетті түрде қоспайды.

Қосылған бөлімдер:

- **Балл және баға:** жеке калькулятор, төрт бағанды кестелер банкі және өзгертілетін 40/65/85 пайыздық шектер. Жаңа жұмыста шкала көшірмесі сақталады; әдепкі баптау өзгерсе, бұрынғы тапсырманың шкаласы өзгермейді. Бұл бір жұмыс нәтижесінің анықтамалық баламасы, тоқсандық баға емес. Бағаланбаған жауап `null` болып қалады; толық тексерілмей пайыз бен баға шығарылмайды.
- **5 тапсырма генераторы:** 5–11 сыныпқа мұғалім енгізген тақырып пен оқу мақсаты бойынша жоба жасайды. Өз Gemini кілті қажет; Free Tier қолжетімділігі мен лимитін Google AI Studio-да тексеріңіз. Кілт бет жадында ғана, сұрау кезінде осы сервер арқылы Google-ға жіберіледі. Серверге, GitHub-қа, браузер қоймасына немесе тапсырма жобасына жазылмайды. Жоба мұғалім қарауынсыз жарияланбайды. Қолжазбаны AI автоматты бағалау бұл жаңартуда жоқ.
- **Тапсырма редакторы:** бағалау критерийі, тапсырма нөмірі, дескриптор және балл бөлек бөлімде; дайын кестені банкке сақтау/қолдану; тапсырма мен нұсқаны көшіру; Excel-ден Tab арқылы бөлінген кесте енгізу.
- **Нәтижелер:** іздеу, бағаланбаған жұмыстар сүзгісі, тек толық бағаланған жұмыстар бойынша сынып көрсеткіштері, CSV-де пайыз және анықтамалық баға. CSV формулаларына айналуы мүмкін мәтіндер қауіпсіз мәтін түрінде шығарылады.
- **Фото жұмыстар:** бір жолы 20 фото — бір файлға бір оқушы; банктегі кестені қолдану, жылдам балл батырмалары, тірі пайыз/баға, сынып/тақырып бойынша іздеу. Фотолар мен олардың бағалары бұрынғыдай тек сол браузердің IndexedDB қоймасында. Басқа құрылғыға көшіру үшін фото бөліміндегі JSON сақтық көшірмесін қолданыңыз.
- **Сілтемені қалпына келтіру:** 404, жабық қабылдау және қосылу қатесі бөлек түсіндіріледі. Жоғалған тапсырманы мұғалім сол token-ге қайта енгізе алады немесе жеке сақтық көшірмеден ашады. Бар token ауыстырылмайды. Бұл жоғалған жауаптарды немесе мазмұнды ойдан қалпына келтірмейді.

Қосымша `bzb_teacher_settings` кестесі мұғалім баптауын алғаш ашқанда `CREATE TABLE IF NOT EXISTS` арқылы құрылады. Қолданыстағы D1 кестелерін жоймаңыз, қайта құрмаңыз. Google OAuth құпияларын өзгерту қажет емес.

Жергілікті тексеру: `npm ci`, одан кейін `npm test`. Node.js 24 қолданыңыз. DOM интерфейсі, сілтеме қалпына келтіруі, баға шектері, 20 фото, settings құқықтары, кестенің тұрақты ұяшықтары және генератор тексеріледі. Gemini жауабы сынақта алмастырылған; нақты кілтпен Google-ға сұрау жіберілген жоқ.

Тапсырманың «Сақтық көшірме» файлында мұғалімнің дұрыс жауап кілттері бар. Оны оқушыларға таратпаңыз. Оқушы жауаптары бұл файлға кірмейді. Фото бөлімінің көшірмесі бөлек.
